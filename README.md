# javascript-calculator-precourse

## 구현할 기능 목록

1.  **입력 받기**
    1.  사용자로부터 문자열을 입력받는다.
2.  **초기 예외 처리**
    1.  입력된 문자열이 빈 문자열일 경우 **0**을 출력한다.
3.  **문자열 파싱**
    1.  **모든 구분자 모으기**: 커스텀 구분자를 뽑아낸 후, 기본 구분자와 모두 합쳐 최종 기준을 정한다.
    2.  **분리 실행**: 정해둔 모든 기준을 사용해 문자열을 한 번에 쪼개 숫자 배열을 만든다.
4.  **유효성 검증 (사용자가 잘못된 값을 입력할 경우)**
    (문자를 입력한 경우, 음수인 숫자를 이용할 경우)
    1.  `[ERROR]`로 시작하는 메시지와 함께 `Error`를 발생시킨 후 애플리케이션을 종료한다.
5.  **계산 및 출력**
    1. 유효성 검증을 통과한 유효한 숫자들을 모두 더하고, 결과를 출력한다.
